Random Workout Picker.
Then a short description paragraph: "A simple Python script that randomly suggests a workout exercise to help you stay active. It uses Python's built in random module to pick one exercise from a list of eight common bodyweight moves, including push-ups, sit-ups, squats, lunges, plank, burpees, jumping jacks, and mountain climbers."
How to run it: Clone or download this repository, then run the script using python workout underscore picker dot p y in your terminal. Each time you run it, a new random exercise will be suggested.
This project helped me practice importing a built in Python module, working with lists, and using the random dot choice function to pick an item at random.
